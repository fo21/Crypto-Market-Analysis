# Crypto Market Analysis

A quantitative analysis project exploring
Bitcoin and Ethereum historical market data.

## Features

- Historical BTC/ETH data retrieval
- Return analysis
- Volatility analysis
- Correlation analysis
- Momentum strategy
- Mean reversion strategy
- Sharpe ratio evaluation
- Maximum drawdown analysis

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- yFinance

## Key Findings

BTC and ETH exhibit strong positive
correlation while displaying periods
of elevated volatility.

Simple momentum strategies generally
outperformed mean reversion strategies
during strong trending market regimes.
